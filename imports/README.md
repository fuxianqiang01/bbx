# 远端导出暂存区

把远端篡改猴导出的原始 .user.js 或 ZIP 放在本目录。除本说明外，内容均被 Git 忽略。

- 请导出截图中的全部 9 个项目脚本，同版本也要核对内容；不导出浏览器配置、Cookie、定位凭据或篡改猴运行存储。
- 导出文件只是待审核输入，不能直接覆盖本地主源码或安装回业务浏览器。
- 对照 config/scripts.json 检查 @name、@namespace、@version、文件头更新记录和源码差异。
- 检查硬编码号码、订单详情、凭据和注释中的真实样例；需要保留的配置使用本机私有配置，测试使用合成数据。
- 审核后的唯一主源码保存到 scripts/<模块固定名称>.user.js；保留 @namespace，避免安装成重复脚本。
- 每个模块分别记录来源、源码版本、SHA-256 和验证结果，再提交到 Git。审核导致的源码变化应留差异记录。
- 导入完成时同步 AGENTS.md、README.md、测试目标和源码登记；版本号一致不代表文件内容一致。

完整流程见 ../GIT_WORKFLOW.md。当前状态：等待用户导出，尚未建立远端源码基线。
